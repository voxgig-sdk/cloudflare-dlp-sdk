Authentication: API key in the header (api_email) or API key in the header (api_key) or bearer token (api_token).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | account_id | path | string | Yes | Account ID. |

Request body

application/json

Property Type Required Description
max_match_bytes integer (int32) No Maximum number of bytes that the regular expression can match. If this is null then there is no limit on the length. Patterns can use * and +. Otherwise repeats should use a range &#123;m,n&#125; to restrict patterns to the length. If this field is missing, then a default length limit is used. Note that the length is specified in bytes. Since regular expressions use UTF-8 the pattern . can match up to 4 bytes. Hence .&#123;1,256&#125; has a maximum length of 1024 bytes.
